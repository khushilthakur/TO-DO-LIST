# Taskora - Todo List Application

Taskora is a web-based Todo List application that allows users to create, manage, organize, and track their daily tasks.

The application is built using **HTML, CSS, and JavaScript** and is integrated with **Supabase** for user authentication and cloud database storage.

Users can sign in with Google and their Todo tasks are stored in the Supabase database.

---

## Project Overview

The main purpose of this project is to create a functional Todo List application with:

- User authentication
- Google Sign-In
- Cloud database storage
- User-specific tasks
- Task creation and management
- Search, filtering, and sorting
- Persistent task data

The application uses Supabase as the backend service.

---

# Technologies Used

- **HTML5** - Application structure
- **CSS3** - Application styling and responsive interface
- **JavaScript** - Application functionality and logic
- **Supabase** - Backend and database
- **Supabase Authentication** - User authentication and sessions
- **Google OAuth** - Google Sign-In
- **PostgreSQL** - Database used by Supabase
